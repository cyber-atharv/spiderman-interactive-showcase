# 🕷️ Spider-Man: Brand New Day — Interactive 3D Cinematic Experience

An immersive, high-performance web experience created to celebrate Marvel's **Spider-Man: Brand New Day**. Featuring interactive canvas scrub animations, fluid GSAP scroll sequences, smooth character spotlights, and cinematic motion graphics.

---

## 🌐 Live Demo

Experience the live website here:  
👉 **[https://cyber-atharv.github.io/spiderman-interactive-showcase/](https://cyber-atharv.github.io/spiderman-interactive-showcase/)**

---

## ✨ Features

- **Cinematic Canvas Hero Scrub**: Seamless scroll-driven image sequence rendering optimized with HTML5 2D Canvas and GSAP ScrollTrigger.
- **Interactive Character Gallery**: Explore Tom Holland's Peter Parker, Zendaya's MJ, Mark Ruffalo's Hulk, and Jacob Batalon's Ned with smooth transitions and spotlight effects.
- **Custom Sound & Visual FX**: Themed Marvel aesthetics with scanlines, glowing webs, and red neon accents.
- **Trailer & Villain Showcase**: Deep dive into the lore and story arcs with responsive video and card interactions.
- **Fully Responsive**: Designed to deliver high framerates across 4K desktops, laptops, tablets, and mobile devices.

---

## 🛠️ Built With

- **Framework**: [Next.js](https://nextjs.org/) (React 19, App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger) & [Framer Motion](https://www.framer.com/motion/)
- **Hosting**: GitHub Pages

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ or v20 LTS recommended)
- npm / yarn / pnpm

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/cyber-atharv/spiderman-interactive-showcase.git
   cd spiderman-interactive-showcase
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run local development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Static Export

```bash
npm run build
```
The static export is generated in the `out/` directory, configured for GitHub Pages deployment.
